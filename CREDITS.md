# CREDITS

`roleplay-data` est une **base de données RP open source** : les données, les visuels et les
traductions sont le fruit de contributions multiples.

> 💛 Merci d'apprécier le travail : quand vous utilisez ce projet (ou ses données) dans le
> vôtre, un petit crédit fait toujours plaisir — un lien, une ligne dans votre README,
> une page « À propos ». Ce n'est pas une obligation, juste une attention.

## Sources des visuels

Certains visuels des packs de thèmes s'inspirent de jeux existants. Chaque thème déclare
sa licence / son attribution dans `themes/themes.json` :

| Thème | Origine des visuels |
|---|---|
| `gta-artwork` | Inspirés de GTA V © Rockstar Games — usage non commercial |
| `artwork-gtav` | Importés de la galerie **RAINMAD** (items.rainmad.com) — voir `themes/themes.json` |
| `dayz` | Générés par la communauté Amity Studio (MIT) |

Si vous ajoutez un thème ou des images, créez vous aussi une entrée dans le registre
`themes/themes.json` (licence + attribution).
